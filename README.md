# Site Kafalis Group

Site statique de kafalisgroup.com, hébergé sur Cloudflare Pages.

- Fichiers publiés : racine du dépôt (`index.html`, icônes, `robots.txt`, `sitemap.xml`).
- Sources : `sources/src/app.html`, puis `python3 sources/build.py` (résultat dans `sources/dist/`, à copier à la racine).

Réglages Cloudflare Pages : aucune commande de build, dossier de sortie `/`.
